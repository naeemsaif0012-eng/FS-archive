# Maison Rose

Maison Rose is a premium editorial e-commerce storefront for a luxury Parisian fashion brand.

## Requirements

- Node.js 20 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5000`.

## Build and preview

```bash
npm run build
npm run start
```

The project uses Next.js, React, TypeScript, and Tailwind CSS. Product data is local and no Replit account, services, or setup are required.
