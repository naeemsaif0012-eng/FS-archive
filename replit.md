# Maison Rose

A premium editorial e-commerce storefront for a luxury Parisian fashion brand.

## Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI primitives**: Radix UI, class-variance-authority
- **Data**: Local static product data in `data/products.ts` — no database or external services

## Project structure

```
app/          # Next.js App Router pages (home, bags, jewelry, accessories)
components/   # Shared UI components (Navbar, Footer, CartDrawer, etc.)
context/      # React context (CartContext)
data/         # Static product data
lib/          # Utility helpers
```

## Running on Replit

The **Start application** workflow runs `npm run dev` on port 5000. Use the webview to preview.

```bash
npm install   # install dependencies
npm run dev   # start dev server on :5000
```
